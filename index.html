How to Use MFA Editor in Any Project

You can copy the assets/ folder or install via NPM (@mirfaisalahmad/editor) into any project (React, Vue, Next.js, Laravel, Django, Node, or plain HTML):

<!-- 1. Include MFA Editor Stylesheets --> <link rel="stylesheet" href="assets/css/dashicons.min.css"> <link rel="stylesheet" href="assets/css/buttons.min.css"> <link rel="stylesheet" href="assets/css/mfa-editor.min.css"> <!-- 2. Target Textarea --> <textarea id="my_editor" class="mfa-editor-area" name="my_editor">Initial content here...</textarea> <!-- 3. Include JavaScript Modules --> <script src="assets/js/jquery.min.js"></script> <script src="assets/js/mfa-editor.js"></script> <script src="assets/js/tinymce/wp-tinymce.js"></script> <script src="assets/js/quicktags.min.js"></script> <!-- 4. Initialize with MFAEditor API --> <script> $(document).ready(function() { MFAEditor.init('my_editor', { tinymce: true, quicktags: true }); }); </script>

JavaScript API Reference:

  • MFAEditor.getContent('my_editor') — Returns current HTML string.
  • MFAEditor.setContent('my_editor', html) — Updates content in visual and text tabs.
  • MFAEditor.switchTab('my_editor', 'tmce' | 'html') — Programmatically switches tabs.
  • MFAEditor.remove('my_editor') — Destroys editor instance cleanly.
